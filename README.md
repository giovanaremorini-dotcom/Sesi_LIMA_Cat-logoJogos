## 📌 Sobre o Projeto

O **GameVerse** é um catálogo de jogos desenvolvido como atividade prática da disciplina de **Desenvolvimento de Sistemas — SENAI/SESI**.

O projeto apresenta uma interface dedicada à exploração de jogos, permitindo que o usuário visualize diferentes títulos, pesquise jogos pelo nome e filtre os resultados por categoria.

A proposta é desenvolver uma página web organizada e interativa, aplicando conceitos de estruturação, estilização e programação para criar uma experiência de navegação intuitiva.

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 🎮 Catálogo de jogos | Apresentação dos jogos em cards |
| 🔎 Pesquisa | Busca de jogos pelo nome |
| 🏷️ Filtros por categoria | Filtragem por tipo de jogo |
| 🗂️ Categorias | Organização dos jogos por classificação |
| 💬 Mensagem de resultado | Exibição de mensagem quando nenhum jogo é encontrado |
| 🎨 Interface visual | Layout organizado e estilizado |

### 🔎 Pesquisa de jogos

O catálogo possui um campo de pesquisa que permite localizar jogos pelo nome.

A pesquisa é realizada utilizando JavaScript, comparando o texto digitado com os nomes dos jogos disponíveis.

### 🏷️ Filtros por categoria

Os jogos podem ser filtrados pelas seguintes categorias:

- Todos
- Ação
- Aventura
- RPG
- Corrida

Os filtros podem ser utilizados em conjunto com a pesquisa por nome.

## ⚙️ Como Executar o Projeto

O projeto pode ser executado diretamente no navegador, sem a necessidade de instalar dependências.

### 1. Baixe ou clone o repositório

```bash
git clone https://github.com/giovanaremorini-dotcom/Sesi_LIMA_Cat-logoJogos.git
```

### 2. Abra a pasta do projeto

Acesse a pasta `Sesi_LIMA_Cat-logoJogos` no Visual Studio Code.

### 3. Execute o site

Abra o arquivo `index.html` no navegador.

> 💡 Para facilitar a visualização durante o desenvolvimento, também é possível utilizar a extensão Live Server no Visual Studio Code.
